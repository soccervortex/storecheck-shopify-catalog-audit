## Two ways to audit

**Read-only Shopify connection**<br>
Connect an owned Shopify store and run a live catalog scan without StoreCheck silently writing product changes through the Shopify Admin API.

**Shopify product CSV**<br>
Upload a Shopify product CSV, review findings, and use the same explainable rule set without connecting a live store.

## Review-first cleanup

StoreCheck separates deterministic data hygiene from merchant decisions. Duplicate/empty tag cleanup can use a guarded safe CSV path with source fingerprinting and post-export revalidation. Pricing, inventory, identifiers, classification and content changes remain review-first.
